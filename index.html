Image Alignment using Pyramid Structures

CS180 Project 1 - Fall 2026

Overview

This project implements image alignment techniques to reconstruct color images from digitized glass plate photographs. The Prokudin-Gorskii collection contains three color-separated channels (red, green, blue) stacked vertically that need to be aligned to create the final color image.

Alignment Methods Implemented:

  • Single-Scale: Direct exhaustive search over shift offsets
  • Multi-Scale: Image pyramid with NCC/L2 scoring

Single-Scale Alignment

Approach

For this part of the project for the single-scale alignment, I implemented an exhaustive search method that looked through a range of [-15, 15] pixels in both x and y directions for the green and red channels relative to the blue channel. The alignment was scored using the L2 norm (sum of squared differences) to find the best offsets that minimized the difference between the channels. The reason I chose the L2 norm is that it is simple to compute and effective for images with consistent lighting and contrast, this allowed for a fast computation time. One of the challenges I faced was the problem with the edges of the images, since the edges of the images were dark boarders the search would sometimes find offsets that aligned the edges of the images, but not the actual content of the images, so I decided to crop the images by 10% on each side to avoid this issue.

Analysis

The alignment results for the provided images were successful, with the channels aligning correctly to produce a coherent color image. For these png images, the single-scale alignment method was sufficient due to the relatively small offsets and consistent lighting conditions. There weren't really significant lighting issues so I didn't have to use NCC for this part, and I decided to L2 for simplicity and speed. And because the picutres are realitivily small, the exhaustive search worked well, because I only needed to go through a range of [-15, 15] pixels. The results were visually pleasing and met the project requirements.

Multi-Scale Pyramid Alignment (40 Points)

Motivation & Approach

Since the TIF files are thousands of pixels wide, a brute-force exhaustive search over the full range would be computationally expensive. I implemented a multi-scale pyramid alignment approach: I recursively downscale each image by 0.5 until it reaches 300 pixels in height. At the coarsest level, I perform an exhaustive search over [-15, 15] pixels. Since the displacement scales proportionally with image size, this search range captures much larger actual displacements at coarser scales. I then propagate the estimated offset up the pyramid, doubling it at each level and refining it locally with a [-15, 15] search. This coarse-to-fine strategy is much faster than searching the full range at full resolution.

Scoring Metric: NCC vs L2

For this part of the project, I used a mix of NCC and L2, originally I started with L2, but with certain pictures the L2 minimization would fail, because the L2 is not robust to brightness variations, so I switched to NCC for a couple of the images. The reason I chose not to have NCC for all the images is because NCC is computationally expensive, if it took 1 minute for L2 to align a picture, I found that it would take NCC 4-5 minutes, so if the pictures were much bigger than the NCC would take even more time, so I decided to use L2 first and final all the alignments that didn't have as many brightness variations, and then I used NCC for all the images that didn't align with L2.
NCC Formula: NCC = sum((im1 - mean(im1)) * (im2 - mean(im2))) / (std(im1) * std(im2))

L2 Formula: L2 = sqrt(sum((im1 - im2)^2))
