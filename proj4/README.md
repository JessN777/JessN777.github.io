# Project 4 report assets

The report is `../project4.html`. Images, homography matrices, the timing table, and written explanations are included. Statements are based on the implementation and current measured outputs; unknown capture information is stated explicitly.

This folder contains display images and this note. The notebook, scripts, points, tests, and numerical JSON files remain in the separate sibling `CS180_project4_data` folder. Run `python export_website.py` from that Python folder after regenerating results. It copies display images and refreshes measured report fields in the publishing checkout `CS180Website1`.

All three mosaics are different pairings of the same three building photos. One input is a 167 x 223 thumbnail, and the rectification's 3:4 target aspect ratio was chosen rather than physically measured. Camera/capture details were not supplied. These facts are stated on the report; see the Python folder's `REVIEW.md` for details.

If the inputs or point selections change, regenerate results, run the export script, and review the discussion, captions, geometry, and cylindrical parameters. Commit and push from `CS180Website1` to publish the report.

A.5 includes a cylindrical panorama, a same-input planar comparison, and a focal-length comparison. These are display images generated by `cylindrical.py` / the A.5 notebook cells in the separate Python project. Numerical measurements remain in that project's `results/extension.json`.
