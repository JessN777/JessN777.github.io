# Project 4 website template

The report is `../project4.html`, alongside Projects 1–3.

## Write your own answers

Open `project4.html` in a code editor. Search for `YOUR ANSWER` or `[Write your answer here.]`. Each gold box contains a question and a blank response. Replace the blank response with your own explanation; keep the surrounding HTML tags. The report does not contain form fields and does not save edits made in the browser.

Fill in the matrices, equations, and runtime table yourself. All scene descriptions and observations are intentionally blank. Once finished, you can remove the question prompts, the gold-box labels/styles, and the draft notice for a final report. The homepage card says “IN PROGRESS”; update it when your report is complete. Its completed-project counter stays at three while Project 4 is unfinished.

## Add your pictures and generated results

Copy original photographs into `images/` and the generated warps, correspondence plots, and mosaics into `results/`, using the filenames below. These names match the earlier Python starter. Run that project's `config.json` after selecting real correspondences, then copy its `images/` and `results/` contents here. If you use different names, change every matching `src` in `project4.html`.

Missing images display labeled placeholders. Added images appear automatically when you refresh. Click an available image to expand it; press Escape or Close to return.
