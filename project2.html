Part 1.1: Convolutions from Scratch! 10 pts

Overview

Convolution is a fundamental operation in image processing. It works by sliding a kernel (filter) across an image and computing weighted sums at each position. In 2D convolution, the kernel is flipped both horizontally and vertically before the operation, distinguishing it from cross-correlation.

Implementation 1: Four-Loop Convolution (Naive)

The straightforward approach with four nested for loops:

# Pad image padded_image = np.pad("CS180Website1\pt2.1.png", pad_width=pad, mode='constant', constant_values=pad_value) output = np.zeros((output_H, output_W)) # Four nested loops: output row, output col, kernel row, kernel col for i in range(output_H): for j in range(output_W): for ki in range(K): for kj in range(K): output[i, j] += padded_image[i+ki, j+kj] * kernel_flipped[ki, kj] return output

Time Complexity: O(H × W × K²) - slow for large kernels

Implementation 2: Two-Loop Convolution (Vectorized)

Optimized version using NumPy vectorization to avoid the inner kernel loops:

def convolve2d_2loops(image, kernel, padding_mode='same', pad_value=0):
    """Convolution with 2 loops and NumPy vectorization."""
    H, W = image.shape
    K = kernel.shape[0]

    kernel_flipped = np.flip(np.flip(kernel, axis=0), axis=1)

    if padding_mode == 'same':
        pad = K // 2
        output_H, output_W = H, W
    else:  # 'full'
        pad = K - 1
        output_H, output_W = H + 2*pad, W + 2*pad

    padded_image = np.pad(image, pad_width=pad, mode='constant', constant_values=pad_value)
    output = np.zeros((output_H, output_W))

    # Two loops: extract patches and compute dot products with vectorization
    for i in range(output_H):
        for j in range(output_W):
            patch = padded_image[i:i+K, j:j+K]
            output[i, j] = np.sum(patch * kernel_flipped)  # Vectorized multiplication

    return output

Time Complexity: O(H × W × K²) - but much faster in practice due to NumPy optimization

Filter Definitions

We use three key filters:

# 9×9 Box Filter (for blurring)
box_filter = np.ones((9, 9)) / 81

# Dx Filter (vertical edges / x-derivative)
Dx = np.array([[-1, 0, 1],
               [-2, 0, 2],
               [-1, 0, 1]])

# Dy Filter (horizontal edges / y-derivative)
Dy = np.array([[-1, -2, -1],
               [ 0,  0,  0],
               [ 1,  2,  1]])

Comparison with scipy.signal.convolve2d

We validate our implementations against scipy:

  • 4-loop vs 2-loop: Results match exactly (within numerical precision)
  • Both vs scipy: Results match - same algorithm, different implementation
  • Speed comparison: 2-loop is ~50-100× faster than 4-loop on typical images

Key Insights

  • Kernel Flipping: Essential for convolution - distinguishes it from correlation
  • Padding: "Same" padding preserves image dimensions; "full" padding includes all partial overlaps
  • Vectorization: NumPy's element-wise operations are vastly faster than Python loops
  • Edge Detection: Finite difference filters (Dx, Dy) effectively capture image gradients
